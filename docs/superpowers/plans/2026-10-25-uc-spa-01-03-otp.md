# UC-SPA-01/03 — Đăng ký và quên mật khẩu bằng OTP email — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 5 endpoint OTP (đăng ký 2 bước, quên mật khẩu 3 bước) gửi mail thật qua Gmail SMTP, đúng `docs/specs/auth.md`.

**Architecture:** `AccountService` (Application/UseCases/Auth) điều phối; OTP lưu ở `otp_codes` qua `IOtpCodeRepository` (cập nhật nguyên tử bằng `ExecuteUpdate`); mail qua `IEmailSender` (Application) ← `SmtpEmailSender` (Infrastructure, MailKit); `resetToken` là JWT audience riêng do `JwtTokenService` phát/đọc. Controller mỏng trong `AuthController`.

**Tech Stack:** .NET 9, EF Core 9 + Npgsql, FluentValidation, MailKit 4.18.1, xUnit + NSubstitute + Testcontainers.

**Spec:** `docs/specs/auth.md` (UC-SPA-01, UC-SPA-03, BR-AUTH-07..13, AUTH-T11..T24)

## Global Constraints

- Tên code tiếng Anh theo glossary; thông điệp người dùng tiếng Việt.
- App Password chỉ ở `.env`; không log App Password, OTP, mật khẩu; log email nhận đã che.
- Không migration mới. Không đổi hành vi UC-SPA-02; mọi test cũ pass.
- Thời gian lấy từ `IDateTimeProvider`; tham số OTP/mật khẩu đọc từ `Account:*`.
- Không commit (người dùng tự chạy git).

**Gửi OTP (chung):** cooldown theo `GetLastSentAt` (đăng ký → 429 kèm số giây; quên MK → im lặng trả 202); `ExpireActive`; Add row + Save; gửi mail; lỗi `ServiceUnavailableException` → `DeleteAsync(row.Id)` rồi ném lại.

**Reset:** đọc subject → user (GetById) null/không active/stamp sai → `invalid_reset_token`; validate mật khẩu; `PasswordHash = Hash(new)`; `RevokeAllActiveAsync`; Save.
