# Đăng ký, đăng nhập, quên mật khẩu trên web — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dựng SCR-W07 (đăng nhập), SCR-W08 (đăng ký 2 bước), SCR-W09 (quên mật khẩu 3 bước) trên web, cùng phiên đăng nhập thật bằng cookie HttpOnly (khôi phục phiên, tự làm mới, đăng xuất, `RouteGuard`) và quy tắc theme.

**Architecture:** `@spa/shared-types` + `@spa/api-client` (`AuthApi`) → `apps/web/src/lib/api` (một `ApiClient` dùng chung, có header `X-Auth-Transport: cookie`, `credentials: 'include'` và tự làm mới khi gặp 401) → `stores/authStore.ts` (Zustand, chỉ trong bộ nhớ) → `features/auth` (hooks, schemas, components) → `pages/public/*`. Phiên được khôi phục một lần khi app khởi động. `RouteGuard` đọc `status` của store.

**Tech Stack:** React 19 + Vite, TypeScript strict, Tailwind v4 + shadcn/ui, TanStack Query 5, Zustand 5, React Hook Form + Zod 4, next-themes 0.4, sonner, Vitest + Testing Library.

**Spec:** `docs/specs/auth.md` — mục "Giao diện (web)" (SCR-W07/W08/W09, "Phiên đăng nhập", "Theme") và "UC-SPA-02 bổ sung — Phiên web bằng cookie HttpOnly (BE-1)". Mẫu bố cục Stitch ghi trong từng màn.

## Global Constraints

- Tên theo glossary. Code ở `apps/web/src/features/auth/` gồm `components/`, `hooks/`, `schemas.ts`, `errors.ts`, `index.ts`. Chỉ named export. Không dùng `any`, `@ts-ignore`, `as unknown as`.
- UI chỉ ghép từ `components/ui` (shadcn) và `components/shared`. Màu chỉ dùng token (`bg-primary`, `bg-muted`, `text-destructive`…), không viết mã màu cứng, không dùng CSS Modules, không dùng `style` inline. Không cần thêm primitive shadcn mới (đã có `alert`, `avatar`, `card`, `dropdown-menu`, `input`, `label`).
- Luồng gọi API: `api-client` → `lib/api` → hook → component. Component không gọi `fetch`.
- Lỗi xử lý theo `ApiClientError.errors[0].code`. Nội dung hiển thị là `message` của server. Riêng `status = 0` dùng câu "Không kết nối được máy chủ. Vui lòng kiểm tra mạng và thử lại.", còn 500 và các lỗi khác toast "Đã có lỗi xảy ra, vui lòng thử lại.".
- Lỗi validation từ server: `field` dạng PascalCase, đổi sang camelCase rồi `setError`. Không dùng `code` của lỗi validation.
- Token: access token chỉ nằm trong bộ nhớ. Refresh token nằm trong cookie HttpOnly do backend đặt. Không ghi bất cứ token nào vào `localStorage`/`sessionStorage`. Mọi request của web gửi `X-Auth-Transport: cookie` kèm `credentials: 'include'`.
- Theme: trang công khai và khu vực khách hàng luôn sáng, không có `ThemeToggle`. Chỉ Staff/Owner có `ThemeToggle` và dark mode.
- Văn bản tiếng Việt có dấu, lấy nguyên từ spec. Giờ của `...AtUtc` hiển thị theo `Asia/Ho_Chi_Minh`.
- Ràng buộc form (BR-AUTH-10): họ tên 1–100 ký tự sau khi bỏ khoảng trắng; email khớp `^[^\s@]+@[^\s@]+\.[^\s@]+$` và ≤ 255; SĐT `^0\d{9}$`; mật khẩu 8–128 ký tự, có ít nhất 1 chữ cái và 1 chữ số; xác nhận phải khớp; OTP `^\d{6}$`; ô đăng nhập ≤ 255 sau khi bỏ khoảng trắng, mật khẩu đăng nhập 1–128.
- Không đổi hợp đồng backend. TDD: test đặt cạnh file (`*.test.ts(x)`), `fetch` giả, không cần backend thật.
- Kiểm tra: `npm run lint`, `npm run typecheck`, `npm run test`, `npm run format:check`, `npm run web:build`.
- Git: người dùng đã cho phép commit trên `feature/uc-spa-01-03-auth-web`. Không push. Không thêm dòng Co-Authored-By hay "Generated with".

## Review Focus

1. **Dán OTP có khoảng trắng hoặc dấu gạch** ("123 456", "123-456") → ô OTP chỉ giữ chữ số, tối đa 6, rồi submit bình thường. Test: Task 5 `OtpInput keeps only digits`.
2. **Bấm gửi hai lần liên tiếp** → chỉ một request được gửi, vì nút đang `loading` thì bị tắt. Test: Task 6 `submits once on double click`.
3. **`redirect` trỏ về chính `/login`, `/register`, `/forgot-password` hoặc URL tuyệt đối** → bỏ qua, về trang chủ theo vai trò (tránh vòng lặp và open redirect). Test: Task 4 `safeRedirect`.
4. **Rời trang khi đồng hồ đếm ngược đang chạy** → interval được dọn, không có cảnh báo cập nhật state sau khi unmount. Test: Task 5 `useCountdown clears its interval on unmount`.
5. **Access token hết hạn, rồi người dùng bấm đăng xuất** → `/auth/logout` không bị vòng tự làm mới chặn lại; đăng xuất vẫn xóa phiên và cookie. Test: Task 2 `does not refresh for /api/v1/auth/* paths`; Task 9 `logout clears session even when the API fails`.
