# Catalog (UC-SPA-06, 07, 09) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend for searching, viewing and managing spa services and packages, with Cloudinary images.

**Architecture:** Application holds four services (`ServiceCatalogService`, `PackageCatalogService`, `CatalogSearchService`, `CatalogImageService`) behind interfaces, plus `ServiceCategoryResolver` and the `IFileStorage` port. Infrastructure adds two repositories whose read queries project straight to DTOs and use an `f_unaccent` SQL function for accent-insensitive search, plus `CloudinaryFileStorage`. API adds four thin controllers and a `catalog.manage` policy built from a permission → roles table.

**Tech Stack:** .NET 9, EF Core 9 + Npgsql, PostgreSQL 17 (`unaccent`, `pg_trgm`), FluentValidation, CloudinaryDotNet 1.29.3 (published 2026-08-16, no advisories), xUnit + NSubstitute + FluentAssertions, Testcontainers.

**Spec:** `docs/specs/catalog.md` (approved 2026-10-26)

## Global Constraints

- Code identifiers in English from the glossary; user-facing messages in Vietnamese with diacritics.
- DI through constructors into `private readonly` fields (same as `AccountService`).
- Application must not reference ASP.NET Core or EF Core; `IFormFile` never leaves the controller.
- `TreatWarningsAsErrors` is on; file-scoped namespaces; one main public type per file.
- Secrets (`CLOUDINARY_API_SECRET`) only in `.env`; never logged; tests never call real Cloudinary.
- Schema change → `docs/spec-source/data_db.py` → regenerate `data-model.md` + Excel → migration; `PersistenceModelTests` must pass.
- UC-SPA-01/02/03 behaviour unchanged; every existing test keeps passing.
- No git commits (the user runs git); "Commit" steps below are replaced by a checkpoint build/test.

## Review Focus

- Vietnamese search: `đ`/`Đ` and stacked diacritics (`ặ`, `ữ`) must match their plain forms → CAT-T04 includes "dau" vs "Dầu" and "da" vs "Đá".
- Search text with `%`, `_` or `\` must be literal, not wildcards → CAT-T04 asserts `search=%` and `search=_` return nothing.
- "Today" crosses midnight between UTC and Vietnam (UTC+7) → CAT-T03 uses 17:30 UTC.
- Editing a package that keeps the same `sort_order` values must not hit the new unique index during delete-then-insert → CAT-T20 resubmits overlapping sort orders.
- Editing a service's category only in case/accents (its own spelling is the only one) must take the new spelling → resolver excludes the service being edited (CAT-T30).
