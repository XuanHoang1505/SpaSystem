# Cart, orders, VNPay payment & promotions (UC-SPA-10, 11, 14) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend for the owner to manage promotions, for customers to keep a cart, preview and create orders (from the cart or "buy now" one product), pay through VNPay sandbox, and receive entitlements on success; a hosted job expires unpaid orders.

**Architecture:** Domain gets `DiscountCalculator` and state-transition methods on `Order`/`Payment`/`Promotion`. Application gets `PromotionService`, `CartService`, `OrderService`, `PaymentService`, `OrderExpiryService`, a shared `PromotionApplier` and `EntitlementIssuer`, and the `IPaymentGateway` port (Application never sees `vnp_*`). Infrastructure adds repositories, `VnpayPaymentGateway`, the `OrderExpiryJob` hosted service and migration `AddOrderingConstraints`. API adds four controllers and three policies.

**Tech Stack:** .NET 9, EF Core 9 + Npgsql, PostgreSQL 17, FluentValidation, `System.Security.Cryptography.HMACSHA512` (no VNPay package), xUnit + NSubstitute + FluentAssertions, Testcontainers.

**Spec:** `docs/specs/orders.md` (approved 2026-10-27: VNPay sandbox; cart + buy now only, no slot hold; hosted-service expiry; Q-19 return URL processed only in Development; Q-20 late success revives `expired` → `paid`; Q-21…Q-23 as written)

- `DiscountCalculator.Allocate(decimal discountTotal, IReadOnlyList<decimal> unitPrices) → IReadOnlyList<decimal>` (same order as input). Algorithm (not determined by the signature):

  ```text
  subtotal = Σ prices; if subtotal == 0 or discountTotal == 0 → all 0
  exact_i = discountTotal × price_i / subtotal; base_i = floor(exact_i); frac_i = exact_i − base_i
  left = discountTotal − Σ base_i
  order indexes by frac desc, then price desc, then index asc; give +1 to the first `left` of them
  ```
