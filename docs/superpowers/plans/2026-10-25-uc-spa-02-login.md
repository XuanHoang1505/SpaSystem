# UC-SPA-02 Đăng nhập JWT + seed chủ spa — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đăng nhập bằng email/SĐT + mật khẩu, phát JWT 15 phút và refresh token 7 ngày xoay vòng, đăng xuất, và lệnh seed tài khoản chủ spa cho dev.

**Architecture:** Nghiệp vụ trong `Application/UseCases/Auth/AuthService` (ADR-0002) dùng các cổng `IPasswordHasher`, `ITokenService`, `IUserRepository`, `IRefreshTokenRepository`; Infrastructure hiện thực bằng ASP.NET Core Identity `PasswordHasher` và `JsonWebTokenHandler`; API thêm JwtBearer, rate limiter và `AuthController` mỏng. Lỗi đi qua domain exception → middleware envelope.

**Tech Stack:** .NET 9, ASP.NET Core, EF Core 9 + Npgsql, `Microsoft.AspNetCore.Authentication.JwtBearer` 9.0.14, `Microsoft.Extensions.Identity.Core` 9.0.14, `Microsoft.Extensions.Options` 9.0.14, xUnit + FluentAssertions + NSubstitute 5.3.0, `Testcontainers.PostgreSql` 4.16.0.

**Spec:** [docs/specs/auth.md](../../specs/auth.md) (UC-SPA-02, seed).

**Git:** làm trên nhánh `feature/uc-spa-02-login` (xem [workflow.md](../../conventions/workflow.md#git)); sau mỗi task chạy `dotnet build` sạch cảnh báo rồi commit theo Conventional Commits.

## Global Constraints

- Dùng SDK 9: `export DOTNET_ROOT="$LOCALAPPDATA/Microsoft/dotnet"; export PATH="$DOTNET_ROOT:$PATH"` trước mọi lệnh `dotnet` (máy này PATH mặc định là SDK 8).
- `TreatWarningsAsErrors` bật: build phải 0 cảnh báo.
- Định danh tiếng Anh; thông điệp lỗi trả client tiếng Việt có dấu; mã lỗi `snake_case`: `invalid_credentials`, `account_locked`, `account_inactive`, `invalid_refresh_token`, `unauthorized`, `forbidden`, `rate_limited`, `validation_error`.
- Access token 15 phút, refresh token 7 ngày — đọc từ `Jwt:AccessTokenExpirationMinutes`, `Jwt:RefreshTokenExpirationDays`; khóa từ `JWT_KEY` → `Jwt:SecretKey`, tối thiểu 32 ký tự.
- Thời điểm dùng `IDateTimeProvider.UtcNow`, tên kết thúc `AtUtc`. Không đọc `DateTime.UtcNow` trực tiếp trong code mới.
- Không sửa schema: không migration mới; `PersistenceModelTests.ModelHasNoChangesMissingFromMigrations` phải vẫn đạt.
- Secret chỉ trong `backend/src/API/.env` / biến môi trường; `appsettings*.json` chỉ chứa giá trị không bí mật.
- Envelope `{ success, message, data, errors, traceId }` cho mọi lỗi, kể cả 401 từ JwtBearer và 429 từ rate limiter.

```text
hash = tokens.HashRefreshToken(request.RefreshToken)
stored = FindByHashAsync(hash)                      → null: throw Unauthorized(invalid_refresh_token)
stored.RevokedAtUtc != null                          → RevokeAllActiveAsync(stored.UserId); SaveChanges; throw Unauthorized(invalid_refresh_token)
stored.ExpiresAtUtc <= now                           → throw Unauthorized(invalid_refresh_token)
stored.User.Status != Active                         → TryRevokeAsync; SaveChanges; throw Forbidden(account_locked | account_inactive)
ExecuteInTransactionAsync:
    TryRevokeAsync(stored.Id) == false               → throw Unauthorized(invalid_refresh_token)   (bị yêu cầu song song lấy trước)
    issue access + refresh mới, AddAsync(RefreshToken mới), SaveChanges
```
