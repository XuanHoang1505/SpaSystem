# Đánh giá dịch vụ (UC-SPA-29, 30, 31) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend cho xem đánh giá công khai (kèm điểm trong catalog), khách gửi/sửa đánh giá kèm ảnh, chủ spa phản hồi và ẩn/hiện đánh giá.

**Architecture:** Thư mục mới `Reviews` theo Clean Architecture như `Staff/StaffCertification*`: phương thức trạng thái trên entity `Review` (Domain); quy tắc thuần `ReviewEligibility`, `ReviewEditPolicy`, `RatingSummary` + 3 service (`ProductReviewService` công khai, `MyReviewService` khách, `ReviewManagementService` chủ spa) trong `Application/UseCases/Reviews`; `IReviewRepository` gom mọi truy vấn; 3 controller mỏng. Một migration thêm hai UQ một phần.

**Tech Stack:** .NET 9, EF Core 9 + Npgsql, FluentValidation, xUnit + FluentAssertions + NSubstitute, Testcontainers PostgreSQL.

**Spec:** [docs/specs/reviews.md](../../specs/reviews.md)

## Global Constraints

- Tên code theo glossary: `Review`, bảng `reviews`, thư mục `Reviews`, route `/reviews`, `/me/reviews`. Enum `ReviewStatus` `visible`/`hidden` có sẵn. `productType` dùng lại `CatalogItemType` (`service`/`package`).
- Thông điệp lỗi tiếng Việt; mã lỗi: `review_not_eligible` (400), `review_exists` (409), `review_locked` (409), `review_not_found` (404); dùng lại `service_not_found`, `package_not_found`, `validation_error`, lỗi ảnh của `ImageUploadReader`/`CatalogErrors.ImageStorageUnavailable` (503).
- DI bằng constructor vào `private readonly _camelCase`; không primary constructor cho dependency. DTO map bằng `ToDto()` viết tay trong `Application/Mapping/`.
- Khách hiện tại luôn là `ICurrentUserService.UserId` (= `customers.id`), không lấy từ body.
- Cấu hình (`ReviewsOptions`, section `Reviews`): `MinCompletedPackageSessions` = 1 (1–100), `CustomerEditWindowDays` = 30 (0–365), `MaxReviewableItems` = 200 (1–1000). Không có biến `.env` mới. Tên người đánh giá công khai = `users.full_name` đầy đủ (Q-77 đã chốt).
- Biên: `rating` 1–5; `comment` trim, rỗng → null, ≤ 1000; `reply` trim, 1–1000. Điểm trung bình làm tròn 1 chữ số, `MidpointRounding.AwayFromZero`, `null` khi 0 đánh giá.
- Không đổi hành vi UC đã xong (catalog chỉ **thêm** `averageRating`, `reviewCount`). Toàn bộ test hiện có pass; `PersistenceModelTests` pass.
- TDD: unit test (NSubstitute, `IDateTimeProvider` giả) + integration test (`PostgresFixture`, `AuthApiFactory`, collection `postgres`); ảnh dùng `FakeFileStorage`.
- `TreatWarningsAsErrors`: build sạch cảnh báo.
- Git do user tự chạy: **không** `git commit`/`push`. Bước "Checkpoint" chỉ đưa lệnh gợi ý; không thêm `Co-Authored-By` hay "Generated with".
