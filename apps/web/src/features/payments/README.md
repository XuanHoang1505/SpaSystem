# payments

Lần thanh toán của đơn hàng (UC-SPA-11, web): `useStartPayment` tạo lần thanh toán và nhận URL VNPay, `redirectTo` chuyển sang cổng, `paymentStatusBadge` map trạng thái. Giao diện thanh toán nằm ở `features/orders` (`CheckoutView`, `PaymentResultView`). Xem `docs/specs/orders.md`, mục "Giao diện (web)".
